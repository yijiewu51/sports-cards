Supabase 同步设置

设置后两人可实时同步数据。首次使用请按以下步骤：

  1. 打开 supabase.com，注册并创建一个免费项目
  2. 进入项目后，点左侧 SQL Editor，粘贴下面的 SQL 并运行：
CREATE TABLE cards ( id TEXT PRIMARY KEY, player TEXT NOT NULL DEFAULT '', series TEXT DEFAULT '', year TEXT DEFAULT '', rc BOOLEAN DEFAULT FALSE, sign BOOLEAN DEFAULT FALSE, mat BOOLEAN DEFAULT FALSE, number TEXT DEFAULT '', buyer TEXT DEFAULT '', source TEXT DEFAULT '', cost_cny NUMERIC DEFAULT 0, sold_price NUMERIC, status TEXT DEFAULT '持有', note TEXT DEFAULT '', created_at TIMESTAMPTZ DEFAULT NOW() ); ALTER TABLE cards ENABLE ROW LEVEL SECURITY; CREATE POLICY "Allow all" ON cards FOR ALL USING (true) WITH CHECK (true);
  1. 点左侧 Project Settings > API，复制 Project URL 和 anon public key 填入下方
